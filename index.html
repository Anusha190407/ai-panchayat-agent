    How the agents work together

    A complaint moves through a state graph. Each agent reads the shared case file, decides, and hands over to the next one. Routers choose the path, so a vague message, a repeat report and an emergency each take a different route.

    Built to be trusted

    • Safety guardrail. Hazard rules (live wire, sewage in drinking water, open manhole) set a minimum priority the AI cannot lower.
    • Never stuck. If Gemini is slow, rate-limited or returns bad output, that step falls back to the offline engine and the trace says so.
    • Full audit trail. Every decision is logged on the ticket with the agent's name and reason.
    • Privacy. Phone numbers are masked; photos are analysed, not stored.

    Built with

    • Google Gemini API (Flash-Lite / Flash) with structured JSON output and photo understanding
    • Python state-graph orchestrator with routers, tools and live streaming
    • Flask, SQLite, browser speech recognition for Tamil and English voice
    • Offline rule engine for Tamil, English and Tanglish as fallback and guardrail

    AI Panchayat is a hackathon prototype. Names, streets and complaints shown are fictional demo data. SMS and WhatsApp messages are simulated.
